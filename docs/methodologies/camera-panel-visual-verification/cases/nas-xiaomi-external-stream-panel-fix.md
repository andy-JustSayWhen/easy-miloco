# 案例：NAS 上小米摄像头底层通道不吐帧，改用外部桥接流并修复面板假空态

返回主文档：[摄像头面板画面修复与验收方法论](../index.md)

## 现象

用户反馈：

- 米家 App 能正常预览摄像头。
- Miloco 面板显示“还没有摄像头在感知”。
- 摄像头开关打开后仍然没有画面。
- 用户要求“面板不出画面不得验收”。

## 初始误区

一开始只看后端状态，很容易误判为已经修复：

| 证据 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| `/health` 正常 | Miloco 服务还活着 | 摄像头画面可用 |
| 目标摄像头在线 | 米家设备状态正常 | NAS 本地已拿到视频帧 |
| 转接流有消费者 | 后端可能在拉流 | 面板已经显示画面 |
| 快照接口返回图片 | 后端缓存已有画面 | 浏览器小窗已经渲染 |

本案最终把验收口径收紧为：必须打开 Miloco 面板并看到真实摄像头画面。

## 根因

问题实际分成两段：

1. 目标小米摄像头对 Miloco 当前原生 SDK 视频通道不吐帧。
2. 后端修到有帧后，前端仍可能因为只按 `connected=true` 展示上方画面卡片，造成短暂或缓存态的“0 个在感知”假空态。

术语说明：

- 原生 SDK：Miloco 直接调用的小米摄像头连接工具。
- 外部桥接流：由 go2rtc 等服务先把摄像头视频转出来，再交给 Miloco 消费。
- 假空态：系统其实有数据，但页面状态仍显示为空。
- LOW：低画质档位，用较小画面换更低本地压力。
- CPU：处理器，负责计算；低配 NAS 上要避免让它长期满载。

## 修复动作

### 后端运行态修复

1. 保持摄像头拉流质量为 LOW，避免低配 NAS 额外吃 CPU。
2. 用 go2rtc 建立小米摄像头视频源。
3. 将 go2rtc 输出的 RTSP 地址写入 `camera.external_streams`。
4. 重启 Miloco 后端，让配置确定生效。
5. 只开启一路目标摄像头，关闭其他摄像头，降低验证噪声。

### 前端固化修复

在首页摄像头区域修正展示条件：

- 原逻辑：只有 `connected=true` 才进上方实时画面卡片。
- 新逻辑：`connected=true`，或“用户已开启 + 摄像头在线 + 不是原生无帧状态”都先显示画面卡片。
- 如果还没连上首帧，在卡片上显示连接中提示。
- 卡片继续使用 `/api/miot/snapshot` 的 JPEG 快照，避免首页常驻直播转码。

对应代码：

- `web/src/components/HeroNow.tsx`
- `web/src/components/LivePlayerPlaceholder.tsx`
- `web/src/api/real.ts::realCameraSnapshotUrl`

## 验证过程

| 步骤 | 合格证据 |
| --- | --- |
| 后端服务 | `miloco-backend` 和 go2rtc 均在运行 |
| 摄像头状态 | 目标摄像头 `in_use=true`、`connected=true` |
| 桥接流 | go2rtc 有生产者和消费者 |
| 快照接口 | `/api/miot/snapshot` 返回 `image/jpeg` |
| 前端静态文件 | 页面引用新的 `index-*.js` |
| 页面文本 | 首页出现 `1 个在感知`，不再出现“还没有摄像头在感知” |
| 页面图片 | 浏览器截图里能看到真实摄像头画面，快照图片尺寸大于 0 |

最终浏览器级证据：

- 首页显示 `1 个在感知`。
- 摄像头小窗显示灰度画面。
- 小窗角标显示“快照”。
- 快照图片加载成功，尺寸为有效非零图片。

## 可复用经验

| 经验 | 说明 |
| --- | --- |
| 验收必须按用户看到的页面闭环 | 只看后端状态会漏掉前端假空态 |
| 米家 App 只能证明摄像头没坏 | 不证明 Miloco 在 NAS 上拿到帧 |
| 低配 NAS 首屏预览优先快照 | 快照比常驻直播更稳、更省资源 |
| 外部桥接流是原生 SDK 不吐帧时的务实路径 | 但必须先验证桥接流本身可播放 |
| 已开启摄像头不应隐藏在下区 | 连接中也要给用户可理解的状态 |
| 验证工具用完即删 | 避免占用用户内存和硬盘 |

## 后续建议

1. 将首页摄像头卡片的状态文案进一步区分为“正在连接”“已出快照”“直播不可用但快照可用”。
2. 在摄像头排障页加入“面板视觉验收”固定步骤。
3. 对原生 SDK 不吐帧机型维护支持矩阵，明确推荐外部桥接流。
4. 给低配 NAS 增加一键导出当前摄像头链路状态的只读诊断命令。
